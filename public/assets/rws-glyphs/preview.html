Using them

Inline or img. Drop the file from svg/color/ straight into markup, or point an <img> at it. Every ID inside is namespaced per glyph, so several on one page never collide.

Sprite. Inject sprite/rws-glyphs-sprite.svg once, then <svg><use href="#rws-dashboard"/></svg>. Mono symbols are #rws-dashboard-mono.

React. import { DashboardGlyph } from "./react"; then <DashboardGlyph size={32} />.

Small sizes. Below about 28px the colour blocks go muddy — use the mono variant, which inherits currentColor.
